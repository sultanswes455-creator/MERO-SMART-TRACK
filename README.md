# ROYAL JACKPOT

A Flutter sports and entertainment application.

## Features

- Black and gold interface
- Arabic and English language support
- Home screen
- Sports section
- Live matches placeholder
- Entertainment games with virtual points
- Account section

## Run

flutter pub get
flutter run

## Demo Notice

This starter version is for demonstration and entertainment.
It does not process real-money bets, deposits or withdrawals.
